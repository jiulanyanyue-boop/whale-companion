公网直连：只映射游戏 UDP

路由器端口映射：外部 UDP 33771 → 房主电脑内网 IPv4 的 UDP 33771。给房主内网地址做 DHCP 保留，并手动允许游戏 UDP 入站。

先核对路由器 WAN IPv4 与运营商分配的公网地址；内网地址、100.64/10、双重 NAT 或运营商入站限制可能使直连失败。Whale 不自动查询公网 IP，不修改路由器或防火墙。TCP 端口检测不能证明 UDP 能联机。

服务器 UDP 中转 尚未配置

  1. 保存服务器地址与端口，生成配套私有部署包。上传到自己的 Linux x64 服务器，以私有权限解压，执行 sh install.sh 下载并校验 frps。
  2. 按包内 README 手动放行服务器控制 TCP 端口和外部游戏 UDP 端口；在解压目录执行 ./frps -c ./frps.toml。脚本不会自动启动服务或改防火墙。
  3. 回本页安装客户端、启动中转，再按下方步骤开房。朋友只填服务器地址和外部 UDP 端口，不需安装 frp，也不需 VPN。

部署包含 token 和服务器私钥，不能发给朋友或公开上传。重新生成会更换凭据和证书，必须将完整新包同步部署到服务器；重复下载当前包不会换凭据。客户端不会随 Whale 自动启动，插件正常退出会停止受管客户端。

你的本机加入端始终填写 127.0.0.1:33771，不能填写公网地址。本机游戏固定 UDP 33771；不要转发或分享 MCP API 15526 或 Whale 管理页面。

实验模式尚未游戏验收。两个窗口必须选择不同的游戏档案，避免共用存档；Whale 未隔离整个游戏用户目录。为避免共享配置让两个实例使用同一个自定义身份，已有自定义 LAN 玩家 ID 时拒绝自动配置。LAN 开房和 IP 加入由你手动操作游戏菜单。

开局步骤

首次启用 Mod 后按游戏提示重启，再从本页启动
  1. 保持 Steam 运行、游戏窗口模式；选择本机双人，一键配置 STS2MCP。
  2. 点击“启动 AI 房主”，在第一个窗口进入“多人 → 创建 / Host”。
  3. 点击“启动本机加入端”，在第二个窗口进入“多人 → 加入 / Join”，自动连接 127.0.0.1:33771。
  4. 选角色、双方准备后开局。第一个窗口由 AI 控制，第二个窗口由你控制。
  1. 保持 Steam 运行，关闭已有游戏窗口；选择 LanSpire 实验模式，保存好友入口，点击“一键配置当前模式”。首次在游戏中启用 STS2_MCP 和 LanSpire 并按提示重启。
  2. 点击“启动 AI 房主”。手动为 AI 选一个独立游戏档案，在多人页点“创建局域网 / Host LAN”，进入角色选择房间。
  3. 点击“启动本机加入端”。为自己选择另一个游戏档案，进入“加入局域网 / Join LAN”，填 127.0.0.1 和 33771，再点击 LAN 加入按钮。
  4. 公网直连先完成路由器 UDP 映射；服务器中转先部署服务端并从本页启动中转。复制上方说明发给朋友，朋友使用同版游戏和 LanSpire，进入 Join LAN，填写分享地址和外部端口。
  5. 确认房间中出现三个不同玩家后再选角色、准备并开局；不要在第三人到齐前开始新 run。AI 在多人局中继续使用现有 STS2 工具。

地图、共同事件、宝箱和结束回合可能需要所有玩家分别投票。停止按钮仅关闭记录身份匹配的受管进程；不会关闭手动启动的游戏。更新或卸载 Mod 前必须关闭游戏。

AI 可以做什么

游戏内 Mod + 本机 REST API

Whale 直接调用本机 STS2MCP，不需要另开 MCP server。仅主人 QQ 私聊、且页面开关开启时允许调用。

  • 读取多人局、自己的角色、队友与战斗状态。
  • 出牌、选目标和卡牌、使用或丢弃药水。
  • 结束 / 撤回回合投票，地图与事件决策。
  • 营火、商店、宝箱遗物、奖励和特殊选择。

当前接入 29 个白名单动作，不开放单人局操控、档案切换/删除或 Wiki 接口。LAN 新增菜单按钮不由 AI 自动点击。通过主人 QQ 对话驱动，未实现持续后台打牌循环。STS2MCP 多人和本页 LAN 三人组合均需实机确认。
