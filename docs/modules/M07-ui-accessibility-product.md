# M07 UI 感知与无障碍：产品功能文档

## 感知

AI 先读取语义树和当前前台包名。只有语义树不足以确认目标时，才使用标记图或视觉模式。

## 动作

支持点击、长按、滚动、输入、返回、主页、最近任务和通知栏。动作后必须重新观察并验证结果。

## 失效处理

以下情况必须停止：

- 快照过期。
- 当前前台包名变化。
- 目标文本、边界、角色或选择器指纹变化。
- 目标不可编辑但请求输入。
- 目标被安全页面覆盖。

## 敏感页面

密码、验证码、支付、系统权限和安全中心默认交还用户。AI 可以等待用户完成后继续，但不能读取或保存敏感值。

## 验收

- 语义树可用时不产生截图请求。
- 树不足时最多产生一次受控视觉观察。
- 旧 snapshot 重放必定失败。
- 注入手势不能点击确认卡自身。
