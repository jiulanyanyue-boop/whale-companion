# M11 OEM 与权限：产品功能文档

## 覆盖目标

标准 Android、华为、小米、OPPO、vivo、魅族；API 26、29、31、34/36 各至少一台测试设备。

## 首次配置向导

按顺序引导：

1. 无障碍服务。
2. 通知权限。
3. 相机/录音/联系人/短信权限。
4. 悬浮窗权限（本地桌宠需要）。
5. 电池优化、自启动、后台运行。
6. 模式和白名单。

每一步显示实际状态；失败时显示品牌和系统版本对应的设置路径，不继续假装在线。

## 权限原则

- 只在用户开启对应功能时申请权限。
- 相册使用系统 Photo Picker，不申请完整存储权限。
- 录音默认关闭。
- 短信发送、联系人读取和相机分别申请，不合并成一个“全部允许”。

## 验收

- 任一权限被撤销后，命令返回明确错误。
- 后台被系统杀死后能显示恢复建议。
- 不同 OEM 的设置页失败不会阻塞普通聊天。
