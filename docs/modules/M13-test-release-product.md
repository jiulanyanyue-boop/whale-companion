# M13 测试、基准与发布：产品功能文档

## 发布门槛

未通过安全、命令、媒体、模式、恢复和 OEM 验收，不得替换旧版或开放公网 WSS。

## 测试层级

- 契约测试：字段、命令、错误码和权限。
- 主机集成测试：OneBot、模型输出、任务幂等、调度。
- Android 单元测试：策略、协议、模式、状态机。
- Android 真机测试：无障碍、相机、相册、语音、悬浮窗、锁屏。
- 多 OEM 回归：华为、小米、OPPO、vivo、魅族和标准 Android。
- 动态任务基准：初始化、执行、成功检查、清理。

## 发布产物

必须包含 APK、版本清单、协议版本、命令目录 hash、测试报告、OEM 矩阵和回滚说明。
