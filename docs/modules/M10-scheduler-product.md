# M10 定时任务与主动问候：产品功能文档

## 功能

支持每日、每周、时间窗口、安静时段、冷却时间和每日上限。用户必须先启用主动问候并选择范围和时间窗口。

## 执行

1. 调度器到点取任务。
2. 检查黑名单、安静时段、每日配额和冷却。
3. 模型返回 `REPLY` 或 `SILENT`。
4. 需要实时手机素材时检查设备在线。
5. 发送文本或媒体并记录 effect。

AI 返回 `SILENT` 是正常结果，不产生空消息。

## 离线

设备离线且任务需要实时素材时进入等待，不重复创建任务；主机已有素材时可以继续发送。

## 验收

- 安静时段内不主动发送。
- 超过每日上限不调用模型。
- 同一调度任务不会重复发送。
- 设备恢复在线后只补执行一次。
