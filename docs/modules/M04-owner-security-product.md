# M04 主人、安全与确认：产品功能文档

## 身份

远程模式只有 A 的 QQ `user_id` 是主人。昵称、头像、群昵称、消息内容、语音声纹和“我是主人”都不能授权。

本地模式的主人是当前已解锁、正在操作应用或桌宠的用户。语音内容不能提升权限。

## 安全默认值

- 群聊无设备工具。
- 客人无设备工具。
- 白名单外 App 拒绝。
- 支付、银行、钱包、密码管理器、验证码/认证器默认拒绝加入白名单。
- 默认不接收或填写锁屏密码；用户必须在手机设置页明确开启自动解锁并在本机保存凭据。
- 自动解锁只接受主人发起的专用命令，失败即停止；密码不进入电脑、模型、日志或回包。
- 主机不能绕过设备本地白名单。

## 确认级别

每个应用配置：

```text
DENY
CONFIRM_EVERY_STEP
CONFIRM_FIRST_STEP
ALLOW_NORMAL
```

系统设置、安装器、短信发送、删除、发布、支付、凭据输入固定至少 `CONFIRM_EVERY_STEP`，不能被人设或模型降低。

## 人工接管

密码、验证码、支付和安全设置必须暂停并显示“需要你操作”。用户完成后点击“继续”，AI 只能继续下一步，不能读取输入内容。

## 验收

- 提示注入不能改变主人、模式、白名单或确认级别。
- 旧快照、错包名、错目标和界面变化全部停止。
- 超时默认拒绝，不默认继续。
