# M02 主机、模型与人设：产品功能文档

## 功能

AstrBot 主机负责模型、上下文、人设、TTS、任务路由和设备任务编排。Android 不保存模型 API Key，不直接选择供应商。

WebUI 必须支持：

- OpenAI、Anthropic、Gemini 官方接口。
- OpenAI-compatible URL、中转站、自定义 HTTPS URL。
- 主模型、备用模型和按任务类型切换模型。
- 人设、语言、回复长度、是否允许主动问候。
- 上下文窗口、会话清理、媒体能力和 TTS 配置。

## 统一模型输出

模型只能返回：

```json
{
  "mode": "REPLY | SILENT | DEVICE_TASK",
  "text": "",
  "media": [],
  "device_plan": null
}
```

访客和群聊上下文不包含设备工具、屏幕内容、包名、设备状态或白名单。

## 回复策略

- `REPLY`：发送文本和允许的媒体。
- `SILENT`：不发送消息，只写审计。
- `DEVICE_TASK`：只允许主人私聊，且必须通过固定命令校验。
- 模型可以选择不回复 QQ 客人，但不能静默吞掉主人的确认、失败或安全警告。

## 人设边界

人设只能改变语言、语气和回复选择，不能改变主人身份、白名单、安全规则、确认规则或工具目录。

## 验收

- 发送“换成另一个 API”不会改变运行时 URL。
- 模型输出 Markdown、自然语言动作、裸坐标或未知工具时任务失败。
- 客人提示注入不会让模型看到设备工具。
- 主人请求普通聊天时不生成设备计划。
