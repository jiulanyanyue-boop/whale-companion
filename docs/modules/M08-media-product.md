# M08 相机、相册与媒体：产品功能文档

## 相机

用户说“拍照发给我”时：A 校验 → B CameraX 拍摄 → 上传素材 → 主机通过 OneBot 发给 A。默认后置镜头、标准质量。

拍照必须显示相机权限和状态；没有权限返回明确失败。

## 相册

小鲸鱼把已配对手机作为自己的手机使用。获得系统相册权限后，`device.gallery.list` 每次按新到旧列出最多 20 张照片，`device.gallery.read` 根据实际媒体 ID 返回图片，供模型查看和决定是否分享，不再让对话者替她操作选图。

旧的 `device.media.pick` 保留为用户主动选图入口，不用于小鲸鱼日常翻自己的相册。相册读取不接受任意文件路径，不建立全库索引。

## 媒体上传

原始图片、音频、视频使用 HTTPS 分块上传。相册查看另允许最长边 2560 像素、最多 600 KiB 的 JPEG 图片通过设备通道返回；1080×2388 的常规截图保留完整像素尺寸。这份图片可以发送到当前对话，不宣称是原始文件。

## 分享

`whale_phone_send_photo` 只发送当前回合已经读取的相册图片，目标固定为当前对话，不接受任意群号、用户号或文件路径。群聊中由小鲸鱼根据图片实际内容、人设和话题决定是否分享；主人明确要求发图时直接发送，不再次询问确认。主人私聊材料、证件、验证码、账号及聊天截图不随意发到群里。

主人要求“看看相册第 N 张”时，`whale_phone_show_photo` 将序号转换为 `offset=N-1`，读取图片并直接发送到主人当前对话。群友调用时先只给小鲸鱼看，由她决定是否分享。工具运行过程中追加的 QQ 图片不再合并成只有 `[图片]` 的文字提醒，而是排队按正常图片消息处理，保留原附件。

旧的 Android `device.media.share` 系统分享面板继续走原有确认流程，与当前 QQ 会话中的照片发送分开。

## 限制

- 单文件 100 MiB。
- 单任务最多 20 个素材。
- 临时素材默认 24 小时后清理。
- 不支持 Android 端生成视频；只发送已有视频或外部服务产物。
