# M05 配对与设备传输：产品功能文档

## 连接方式

首版支持两种配置：

1. Tailscale/WireGuard 私网内手机主动 WSS 连接主机。
2. 公网 HTTPS/WSS，使用设备令牌、TLS、设备身份和主机身份指纹。

手机不开放入站端口，主机不要求家庭路由器端口映射。

## 配对流程

1. 主机生成一次性配对码和短期 token。
2. B 扫码或手动输入配对码。
3. B 生成 Android Keystore 身份密钥。
4. 主机保存 B 的 `device_id`、公钥、能力版本和连接配置。
5. 双方显示设备名称和指纹，用户确认后才启用。
6. 配对完成后一次性 token 立即失效。

## 断线行为

- 网络断开时任务暂停，不重复执行已经完成的命令。
- B 重连后先发送状态和最后计数器，再恢复可恢复任务。
- 超过租约或身份指纹变化，必须人工重新配对。

## 验收

- 私网和公网 WSS 都能完成配对。
- 错 token、过期 token、错误主机指纹和重复 counter 拒绝。
- 主机重启、手机进程被杀、网络切换后只恢复一次。
